# Elena Portfolio Neon

Креативное портфолио Елены Саманчук в неон-эстетике ZERO Awakening: scroll-story, глитч, custom cursor и кейсы с живыми ссылками.

Отдельный проект — не заменяет [elena-samanchuk](https://elenasamanchuk.github.io/elena-samanchuk/) и [zero-awakening](https://elenasamanchuk.github.io/zero-awakening/).

## Локально

```bash
npm install
npm run dev -- -p 3457
```

## GitHub Pages

```bash
GITHUB_PAGES=true npm run build
```

Деплой через `.github/workflows/deploy-pages.yml` при push в `main`.
